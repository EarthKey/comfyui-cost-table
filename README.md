# ComfyUI Video API Cost Table

ComfyUIパートナーノードの動画生成APIのコスト比較表です。
最新のクレジット計算に基づき、5秒あたりのコストを可視化しています。

## 概要
- ComfyUI公式ドキュメント（[pricing](https://docs.comfy.org/ja/tutorials/partner-nodes/pricing)）のデータを基盤に作成
- $1.00 USD = 211 credits 換算
- 5秒あたりのコスト（USD/CR）でモデルを比較

## 公開先
GitHub Pages等で `index.html` をホストすることで、インタラクティブな比較表として閲覧可能です。
