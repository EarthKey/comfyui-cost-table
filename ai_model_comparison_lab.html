# 会社 モデル・条件 総合知能指数 ↓ Coding Agent Index 入力 $/1M 出力 $/1M 簡易混合価格※ 知能/簡易価格 Context 主な特徴

⚠ Coding Agent Index はモデル単体の成績ではありません。 「モデル ＋ 推論レベル ＋ エージェント基盤」（例: GPT-5.6 Sol + Codex、Claude系 + Claude Code、Grok 4.5 + Grok Build）の組み合わせ評価です。 異なるIDEやCLIで同じ点数が再現される保証はありません。

指標の定義

  • 総合知能指数 = Artificial Analysis Intelligence Index v4.1。GDPval-AA v2、Terminal-Bench v2.1、SciCode、Humanity's Last Exam、GPQA Diamond など複数評価の合成値。高いほど総合的な推論・知識・科学・コーディング能力が高い。
  • Coding Agent Index = DeepSWE、Terminal-Bench v2、SWE-Atlas-QnA で構成されるコーディングエージェント評価。
  • 入力/出力単価 = 100万トークンあたりの標準価格（USD）。推論モデルは出力側の費用が支配的になりやすい。

簡易混合価格の計算式

「入力80万 + 出力20万 = 計100万トークン」の仮想ワークロードで比較する簡易指標です。

簡易混合価格 = 入力単価 × 0.8 + 出力単価 × 0.2
知能/簡易価格 = 総合知能指数 ÷ 簡易混合価格

これは実際のエージェント費用ではありません。キャッシュ、推論トークン量、再試行、ツール呼び出し、長文料金を無視しています。

数値を鵜呑みにできない理由

  • ベンチマークは実務そのものではない。数点差は常に体感できる絶対差ではない。
  • 推論レベルを上げると性能と消費量が同時に上がる。
  • Codex、Claude Code、Grok Build などエージェント基盤の差が大きい。
  • Claude Sonnet 5 は新Tokenizerが同じ文章を約30％多いトークンに分割するため、同じ名目単価でも請求トークンが増える可能性が公式に明記されている。
  • Gemini 3.5 Flash は同価格帯の推論モデルより出力トークン量が多めと報告されている。
  • Artificial Analysis の指数は評価バージョン更新で変動する。
