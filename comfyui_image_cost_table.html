トークン課金のモデル（gpt-image / Nano Banana）

OpenAI の gpt-image 系と Google の Nano Banana 系は、1枚いくらではなく出力トークン1,000個あたりいくらで課金されます。 ComfyUI公式ドキュメントも「quality（low / medium / high）による概算バッジ。実費は下のトークン数に従う」と明記しています。 つまり同じモデルでも品質設定で単価が15倍以上変わるため、上の表と同じ土俵には並べられません。 ここでは1枚に何トークン使うかを掛け合わせて、枚数単価へ換算しています。

⚠ この表は「クレジット単価（ComfyUI公式）× 1枚あたりトークン数（各社の公式値）」の掛け算です。 トークン数の確からしさは行ごとに違うので、バッジで区別しています。
公式表 OpenAI公式が公表しているトークン表の値。gpt-image-1 / 1.5 はこれ。
推定 Google が公表する「画像1枚 = 1,290トークン」を全Nano Banana系に当てはめた値。上位モデルで実際のトークン数が違う可能性があります。
未公表 gpt-image-2 だけは OpenAI がトークン表を公開しておらず、計算機での見積りに誘導されています。掲載値は第三者が報告している1枚あたり単価からの逆算で、もっとも確度が低い行です。実運用の前に少量で実測してください。
# 会社 / モデル 品質 サイズ 出力トークン 出力 CR/1K CR / 枚 円 / 枚 手持ちで 確度
★ クレジット→ドルの換算（211cr = 1 USD）は公式の明示ではなく、各社の公開API価格からの逆算です。 Flux.1 Kontext [pro] 8.44cr ÷ $0.04、Kontext [max] 16.88cr ÷ $0.08、Flux.1 Fill 10.55cr ÷ $0.05、DALL·E 3 標準 8.44cr ÷ $0.04、DALL·E 2 3.38cr ÷ $0.016 ——5行すべてで211に一致したため、この係数を採用しています。 公式ドキュメントは「価格はすべてクレジット表記」としか書いておらず、レートの記載はありません。
★ 円換算は 1 USD = 150円の概算です。実際の請求はComfyUIのクレジット購入時のレートに従います。
★ 「+ 追加MPあたり」表記のモデル（Flux.2 [pro]/[max]、Flux Erase、Flux Virtual Try-On）は、基本料金のみを表に載せています。 大きい画像を作るほど加算されるため、実額は表の数字より高くなります。条件欄に加算額を書いてあります。
★ Recraft の Text to Vector は SVG 出力です。ラスタ画像より単価が高く設定されています。
★ Qwen Image の Edit は入力画像ぶん +0.91cr が別途かかります。
★ Krea は Style Reference / Moodboard を付けると単価が上がります。3段階すべてを別行として掲載しています。
★ Seedream 5.0 Pro Layer Separation (2K) のみ公式表記が 6.75〜13.50 の幅で、表には上限値を載せています。
★ grok-imagine の edit タスクは入力ぶん（0.422〜2.11cr）が別途加算されます。表は generate（生成）の値です。
★ gpt-image 系の「品質」は単価を15倍以上変えます。 同じ gpt-image-1.5 でも 1024×1024 の low は 1.84cr、high は 28.09cr。 ここを既定のまま回すのが、画像APIでいちばん静かにクレジットが溶ける場所です。用途が下書きなら low で足ります。
★ gpt-image-2 だけ確度が落ちます。 OpenAI公式のトークン表は「gpt-image-2 より前のモデル向け」と明記されており、 gpt-image-2 は計算機での見積りに誘導されています（「サイズと品質が上がるほどトークンが増える」とだけ記載）。 表の3行は第三者が報告している1枚単価からの逆算で、他の行と同じ精度では扱えません。
★ Nano Banana系の「1枚 = 1,290トークン」は gemini-2.5-flash-image の公表値で、上位のPro・2系も同じと仮定しています。 実際のトークン数が違えば単価もそのぶんズレます。
★ ローカル実行（Stable Diffusion / Flux dev / Qwen Image ローカル版など）はクレジットを消費しません。 この表はすべてAPI経由の価格です。
★ 価格は予告なく変わります。取得日は2026-08-17。判断の前に出典を直接確認してください。
