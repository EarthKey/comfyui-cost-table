# 会社 / モデル ComfyUI追加日 🆕 解像度 音声 CR/秒 5秒CR 5秒USD コスパ ELO スコア ★ コスト感
【2026-09-04 更新】前回（8-08）以降の変化 — 新規11モデル・提供終了4件・ELO全面改訂
★ 「ComfyUI追加日」列を新設しました。これはComfyUI本体にパートナーノードとして実装された日で、ベンダーの公式発表日ではありません。出典は ComfyUI 本体リポジトリ（Comfy-Org/ComfyUI の comfy_api_nodes）のコミット履歴で、該当PRがマージされた日を採っています。「頃」が付いた日付は、モデル単位のPRを特定できずノードファイルの初回導入日で代用した概算です（例：2025-05-06 の More API Nodes #7956 でLuma・Kling・Pixverse・Minimaxが一括導入）。「不明」はノードが既に削除され追跡できないものです。
──────────
★ 🔥 Wan 3.0（8-24追加 / Prime は 8-26）が最大の新顔。Arena T2V 2位・ELO 1238 で 480P が 15.09cr/秒（5秒 75.5cr）。音声ネイティブ生成つきでこの価格帯は現時点で最強のコスパ。720Pでも 30.17cr/秒で、Seedance 2.0 720P（45.62）より安く品質は上。Prime は約1.4倍の価格だがArena未評価なので、まず無印から試すのが妥当。
★ 🔥 MiniMax H3 Max（9-02追加・ごく最近）が Arena T2V 3位・ELO 1235。docs.comfy.org には未掲載なので、ComfyUIのノード価格バッジを実機で読んだ値を掲載しています。5秒で 480P 75.4cr・768P 120.7crで、T2V・I2V・FLF（最初・最後フレーム）はすべて同額——つまり価格はモードではなく解像度で決まります。
　　→ 🔴 例外は R2V（参照からビデオ生成）だけ。ここだけバッジが幅を持ち、480P 75.4〜112.5cr／768P 120.7〜157.8cr。増分はどちらも +37.1cr で一定で、image_2 / video_1 / audio_1 の追加入力分と見られます（本表には下限と上限の両方を行として立ててあります）。参照を盛るほど高くなるので、見積もりは上限側で立てるのが安全です。
　　→ ここが今回一番の発見です——① 通常のH3に無い 480P が選べる（通常H3の最低は768P） ② 768P が 24.14cr/秒で、通常のH3 768P（27.16）より安いのに ELO は 1235 > 1227 で上。H3を使うなら Max を選ばない理由が現時点で見当たらない。（2K の実額は未取得）
★ MiniMax H3 Context IR（Prompt Enhancer）は別課金で 約12.7〜23.2cr/Run（実測）。本表の生成コストには含まれませんので、使うならその分を上乗せして見積もってください。
★ 【ComfyUIと fal の差】H3 には fal（別のホスティング先）だと Turbo がありますが、ComfyUI のノードにはありません。ソースを見ると選べるのは MiniMax H3 と MiniMax H3 Max の2つだけで、Turbo のモデルID は存在しません（2026-09-04時点）。高速化を狙うなら ComfyUI では現状手がありません。
　　→ なお ComfyUI の H3 Max 自体が fal 経由のプロキシです（エンドポイントは /proxy/fal/minimax/h3-max）。Arena で Minimax H3 Max (post-trained by fal) と表記されているものと同じ実体なので、ELO 1235 はそのままこのノードの実力として読めます。
　　→ H3 Max の細かい制約（ソース由来）: R2V の参照は合計最大 12 ファイル。ウォーターマークの設定は通常の H3 専用で、Max では使えません。
★ 🔥 Gemini Omni 1.1（8-27追加）。前回「約21cr/秒（概算）」と1行で載せていた Gemini Omni Flash は誤りでした。公式に解像度別の正価が掲載され、360P 10.19 / 720P 30.57 / 1080P 45.87 / 4K 91.76 cr/秒と判明。720Pの実額は概算の約1.5倍です。本表は4解像度に分割し、1.1 と Flash の両方を掲載しました。360Pなら5秒50.95crでArena1位品質という点は変わりません。
★ PixVerse V6（8-25追加・ELO 1074）は360P〜1080P × 音声ON/OFF の8区分。360P音声OFF 15.09cr/秒が最安。
★ LTX-2.5（8-11追加）は Pro 1061 / Fast 1060 でLTX-2世代（921〜941）から大幅に改善。Fast は4K（90.52cr/秒）まで対応。
★ MiniMax H3 Regenerate → 2K（8-13追加）が15.09cr/秒と安い。作り直しではなく既存H3動画の2K焼き直し専用で、H3 2K（39.22）の4割で済む。
★ 高画質化・編集の専用ノードが増えた：ByteDance vCube Video Enhance（8-22・1080P 20.78cr/秒）、Flux Video Upscale（8-20・出力メガピクセル×秒の課金）、FLUX 3 動画継続（720P 123.71cr/秒）、Seedance 2.5 の動画延長（8-15）。
